What this site does

The Ledger is a small collection of financial calculators — mortgage refinancing, auto loans, mortgage points, and home affordability. Each one takes the numbers you enter, runs the math in your browser using JavaScript, and shows you the result. No part of that calculation is sent to a server. There is no server involved in the calculation at all.

What we collect

Directly, from the calculators themselves: nothing. We don't ask for your name, email, or any contact information to use any tool on this site. Loan balances, income figures, interest rates — none of it is transmitted, logged, or stored by us in any form.

Like virtually any website, the server that hosts these pages (and any content-delivery network in front of it) automatically logs basic technical information for every visit — your IP address, browser type, and the page requested — as a standard part of serving web pages. This is infrastructure-level logging, not something this site collects or uses for any purpose beyond keeping the site running.

Cookies & local storage

This site does not set cookies. It does not use browser local storage or session storage. Nothing persists between visits — reload any calculator and it starts fresh, because there was never anything to remember.

Third-party services

Pages on this site load typefaces from Google Fonts. When your browser fetches those font files, it makes a direct request to Google's servers, which — like any web request — includes your IP address. We don't control this exchange or receive any data from it ourselves. Google's own privacy policy governs what happens on their end.

Advertising & affiliate links

This site does not currently display ads or contain affiliate links. If that changes, this section will be updated with specifics — which network, what they track, and how to opt out where applicable. Any outbound link to a lender, product, or service takes you to a site outside our control, governed by that site's own privacy policy, not this one.

Analytics

This site does not currently use any analytics or visitor-tracking tool. If one is added, this section will name the specific tool, describe what it measures, and explain any opt-out available.

Children's privacy

This site is not directed at children under 13, and we do not knowingly collect information from anyone in that age group — which is straightforward here, since we don't collect personal information from any visitor, of any age.

Changes to this policy

If what this site collects or how it's hosted changes, this page will be updated and the date at the top will change. Significant changes — like adding analytics, ads, or any form that asks for personal information — will be reflected here before they go live, not after.
